Serveur communauté

Le mode communautaire complet est fourni par communaute/serveur_communaute.py. Pour protéger les données sociales et les comptes, il se lance comme service séparé sur le réseau local.

Aucun post n'est affiché tant que ce service n'est pas connecté.
