Installer (2 minutes)

  1. Désinstallez d'abord l'ancienne version de La Trattoria si elle est encore installée (appui long sur l'icône → Désinstaller).
  2. Toucher le bouton « Télécharger l'application » ci-dessus.
  3. Ouvrir le fichier téléchargé (notification, ou application Fichiers → Download).
  4. Si Android demande d'autoriser les applications inconnues : Autoriser.
  5. Si un écran Play Protect apparaît : « Plus de détails » → « Installer quand même ».
  6. Toucher Installer puis Ouvrir. C'est prêt.
⚠️ Message « Application non installée » ? → Une ancienne version est encore installée : désinstallez-la, puis réessayez (les clés de signature changent entre les grandes séries de versions, Android refuse la mise à jour dans ce cas).

Après l'installation

  • Lancez La Trattoria : le serveur démarre automatiquement.
  • ✏️ Éditer les cartes : panneau en haut de l'écran d'accueil de l'app (carte standard, formules, vins, glaces, bières, ardoise & QR).
  • Astuce : sur la tablette, ouvrez 127.0.0.1:8720/?carte dans Chrome puis ⋮ → Ajouter à l'écran d'accueil : une icône « Éditer les cartes » sera posée à côté de l'application.
  • Tout est publié automatiquement sur le site clients.
